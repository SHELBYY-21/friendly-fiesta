# คู่มือพนักงาน CT Desk

เปิดโต๊ะ: https://ce-vault.vercel.app

## ทุกกวารทำอะไร
1. ใส่รหัส 6 หลัก
2. ปักบัญชีรับของวัน (สูงสุด 3 บัญชี)
3. ลูกค้าส่งสลิปในห้อง Telegram — อย่าส่งรูปในเว็บ
4. กดแถวดูรูป+ยอด · บัญชีต้องตรงที่ปัก
5. โอน USDT จริง แล้วกด **บันทึกส่งรวม**

## คำบนโต๊ะ
|บุ่ม|ความหมาย|
|---|---|
|คิว / QUEUE|รอโอน|
|พัก / HOLD|จอดไว้ · ไม่นับในยอด DUE|
|KEEP|ยกรายการพักกลับคิว (ยอด≥20,000 ต้องยืนยัน)|
|เสร็จ / DONE|บันทึกแล้ว|
|ผิด / ERR|อ่านไม่ได้ · ห้ามส่งหรือแก้บยอด|
|เริ่มใหม่|พักคิวเดิม · ไม่ลบ · ไม่โอนเงิน|
|set rate|ตั้งเรทขายของห้อง|

## ห้าม
- บอทไม่ตอบ — ส่ง `/ping` ในห้อง Telegram
- สลิปไม่ขึ้นโต๊ะ — ตรวจว่าปักบัญชีแล้ว
- ยอดผิดเป็น 10 ล้าน — อ่าน OCR ผิด · ไม่กดส่ง
